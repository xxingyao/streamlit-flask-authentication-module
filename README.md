## 📖 Overview
This repository documents the user stories that drive our product development. Each story focuses on **who** wants something, **what** they want, and **why** it matters.

**User story format:**  
_As a `<role>`, I want `<capability>` so that `<benefit>`._

## Epic 4 (Control Access for Data Management)

1. **User Story 1**  
   As a System Administrator, I want to assign roles and permissions to users so that I can control who has access what sensitive data.

   As a System Administrator, I want to ensure that only the Commanding Officer can access the CEP and AFR records of all personnel so that he has exclusive visibility into these sensitive information.

3. **User Story 3**  
   As a System Administrator, I want to ensure that only the relevant personal profile so that I can confirm my records are accurate without accessing others’ information.
